# ブラジルポルトガル語 学習帳 🇧🇷

日本語話者のためのブラジルポルトガル語 学習アプリ。一般語彙 **1,002語** ＋ カポエイラ専門 **293語** を、
言語習得で効果が高いとされる **間隔反復(SRS)・能動的想起・文脈学習・発音支援** で学べます。

## 学習機能

| 機能 | 内容 |
|------|------|
| 📇 単語帳 | 50語ずつ・目隠し(一括/個別タップ)・音声個別/連続再生(0.8/1.0/1.2x)・SRS評価・カナ/IPA発音ガイド・例文 |
| 🎯 クイズ | 10問ランダム・3モード(葡→和 / 和→葡 / リスニング)・**学習済みの語から出題**(既定)・復習画面・結果をSRSに反映 |
| 🔁 パターンプラクティス | 文型のスロットを語彙で入れ替えて発話練習 |
| 📖 チャンクリーディング | 意味のカタマリ(/)で**1行ずつ改行した連結長文**を前から理解・チャンク個別/全文音声・訳の出し入れ(サイトトランスレーション) |
| 🗣️ シャドーイング | **まとまった長文パッセージ**をお手本音声(0.8/1.0/1.2x)で・**スクリプト非表示**(音だけで挑戦)・マイク録音で聞き比べ |
| ✍️ ディクテーション | 4ステップ(聴取→語彙予習→ヒント入力→訳＋**オーバーラッピング**)・3レベル(短/中/長)・一覧は答えを伏せる |
| ➕ 教材を追加 | ポルトガル語テキストを貼り付け→自動チャンク分割→自分の教材に |
| 🎵 音楽 | YouTube再生リストを再生・**同期歌詞**(現在行ハイライト/自動スクロール/行リピート/1行ずつ停止/0.75x)・**和訳**(端末から無料機械翻訳→行ごとに編集)・**歌詞の単語をタップ→原形・活用・意味・発音→SRSに追加**・曲ごとの単語一覧 |

- **間隔反復(SRS)**: SM-2簡易版で復習タイミングを自動最適化。ホームに「今日の復習」「新規語」「ストリーク」「習熟度」を表示。
- **発音ガイド**: pt-BRの発音規則をルールベースでカタカナ/IPAに自動変換（全語対応）。
- **音声**: ブラウザ内蔵の音声合成(Web Speech API, pt-BR)。`src/services/audio.ts` を差し替えれば将来クラウドTTSや録音音源にも対応可能。

## 使い方

```bash
npm install      # 初回のみ
npm run dev      # 開発サーバー (http://localhost:5173)
npm run build    # 本番ビルド (dist/ に静的ファイル生成)
npm run preview  # ビルド結果をプレビュー
npm run enrich   # データ検証＋発音プレビュー生成(data/_pronunciation-preview.json)
npm run check:lemma     # 原形推定の回帰テスト
npm run check:dict      # 一般辞書の検証（追記専用・重複・品詞）
npm run music:pin       # 各曲の歌詞の版(LRCLIB ID)を固定（数値のみ保存）
npm run music:coverage  # 辞書カバー率の計測（集計値のみ出力）
```

> **OneDrive 上のビルドについて**: 本プロジェクトは OneDrive 同期フォルダ内にあり、同期がビルド出力(dist)のファイルをロックすると Vite がクラッシュすることがあります。これを避けるため `npm run build` は内部で **同期外の一時フォルダにビルドしてから dist/ へ複製** します(`scripts/build.mjs`)。`dist/` への複製に失敗した場合も成果物は一時フォルダに残り、メッセージに場所が表示されます。OneDrive を一時停止すれば確実に dist/ に出力できます。なお `npm run dev` は影響を受けません。

スマホでも利用可能（PWA対応。音楽タブ以外はオフライン動作。ブラウザの「ホーム画面に追加」でインストール）。
※シャドーイングのマイク録音は `localhost` または HTTPS 環境で動作します。
※音楽タブはオンライン必須です。歌詞は再生時に [LRCLIB](https://lrclib.net) から端末で取得し、端末内にだけ保存します（**歌詞・和訳はアプリに同梱していません**）。`index.html` を `file://` で直接開くと YouTube 埋め込みが再生できないため、`npm run dev` / `npm run preview` などの http(s) で開いてください。音楽タブを離れる・画面をロックすると再生は止まります。

## 🎵 音楽タブ

- 再生リストは `data/music-playlists.json`（動画ID・曲名・アーティスト・長さ・LRCLIBの版IDのみ）。曲を追加したら `npm run music:pin` で歌詞の版を固定します。
- **単語の意味はオフライン辞書**で表示します: 単語帳（1,295語）＋一般辞書 `data/dict-words.json`。活用形・複数形・縮約（do = de+o）・口語（tô, pra, cê）から原形を推定します（`src/services/lemmatize.ts`、不規則動詞は `data/verb-irregular.json`、縮約/口語は `data/colloquial.json`）。
- 辞書に無い語は、シートで機械翻訳の候補を出し、意味を直して自分の単語として追加できます。
- 曲から追加した単語は「🎵 曲の単語」デッキに入り、今日の学習（1日の上限は設定で変更可・一般語彙の新規枠とは別）とクイズにも出ます。
- 歌詞のタイミングがずれる曲は「同期 ±0.5s」または「⏱合わせる」（歌われている行の時刻ボタンをタップ）で調整できます（曲ごとに保存）。

## データの編集・追加

学習データはすべて `data/` 配下のJSON（手編集しやすい形式）。

- `words.json` / `capoeira-words.json` … 単語（`カテゴリ/ポルトガル語/日本語/品詞`）
- `examples.json` … 単語ごとの例文・コロケーション（キー=小文字のポルトガル語）
- `patterns.json` … パターン練習の文型
- `passages.json` … チャンクリーディングのパッセージ
- `scripts.json` … シャドーイングのスクリプト
- `dictation.json` … ディクテーション項目
- `pronunciation-overrides.json` … 自動生成が不自然な語のカナ/IPA上書き辞書
- `music-playlists.json` … 音楽タブの再生リスト（メタデータのみ。歌詞は含まない）
- `dict-words.json` … 歌詞引き用の一般辞書（**追記専用**: ID が `dict:インデックス` のため並べ替え・削除禁止。誤りは日本語の修正か品詞 `_deleted` で対応。`dict-words.lock.json` で機械的に検査）
- `verb-irregular.json` … 不規則動詞の活用表（省略した時制は規則形・完了過去3複から自動派生）
- `colloquial.json` … 縮約形・口語形・間投詞の分解表

例文のカナは自動生成されるため、`examples.json` には `pt` と `ja` だけ書けばOKです。

## 学習進捗のバックアップ

進捗はブラウザの localStorage に保存されます。設定画面から **JSONエクスポート/インポート** で
別端末への移行やバックアップができます。音楽タブの和訳（自分で編集した訳を含む）・同期調整・曲から追加した単語も含まれます（歌詞そのものは含みません）。

## 技術構成

Vite + React 18 + TypeScript + Tailwind CSS + Zustand（永続化）+ vite-plugin-pwa。バックエンド不要。
