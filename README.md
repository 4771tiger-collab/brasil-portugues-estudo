# ブラジルポルトガル語 学習帳 🇧🇷

日本語話者のためのブラジルポルトガル語 学習アプリ。一般語彙 **1,002語** ＋ カポエイラ専門 **293語**（＋歌詞引き用の一般辞書 3,784語）を、
言語習得で効果が高いとされる **間隔反復(SRS)・能動的想起・文脈学習・発音支援・発話練習** で学べます。
Android の Chrome で使う PWA です（バックエンド無し。学習データは端末の中だけに保存）。

## 公開 URL と Android でのインストール

**https://4771tiger-collab.github.io/brasil-portugues-estudo/**

1. Android の **Chrome** で上の URL を開きます。
2. ホームの「アプリとしてインストール」の **インストール** ボタン、または Chrome のメニュー **⋮ →「アプリをインストール」**（機種によっては「ホーム画面に追加」）でインストールします。インストールすると、ブラウザが学習データを消しにくくなります（設定の「データ保護」で状態を確認できます）。
3. 音声は端末の読み上げ（Google 音声サービス）を使います。pt-BR の音声が無いときは、設定の「Android で pt-BR の音声を入れるには」の手順で音声データを入れてください。
4. **更新**: 新しい版を配信すると、アプリを開き直したときにホームと設定に「新しいバージョンがあります」のバナーが出ます。「更新」を押すと画面を読み直します（学習の記録は消えません。学習の途中の画面ではバナーを出しません）。
5. **バックアップ**: 設定 →「⬇ バックアップを保存」で、Android では共有シートが開きます（Google ドライブ・メールなどへ）。ファイルは **.txt**（中身は JSON）ですが、そのままインポートできます（Chrome の共有は .json を送れないため）。PC では .json をダウンロードします。ホームには、前回から7日以上たつか 200 回以上評価すると保存の案内が出ます。
6. **インポート**: ファイルを選ぶか、テキストを貼り付けます。既定の **統合（推奨）** は、この端末の記録とバックアップの記録を合わせます（同じ語は新しく学習した方を残し、設定はこの端末のまま）。PC とスマホの記録をまとめるのにも使えます。**置き換え** は、この端末の進捗・曲のデータ・設定をバックアップの内容にします。

音楽タブ以外はオフラインでも動きます。シャドーイングのマイク録音は HTTPS（公開 URL）か `localhost` で動作します。音声認識の「🎤 言ってみる」（任意。既定はオフ）はオンラインのときだけ使えます。

| 📇 単語帳（一覧） | デッキ別に50語ずつ・目隠し(一括/個別タップ)・音声個別/連続再生(0.8/1.0/1.2x)・SRS評価・カナ/IPA発音ガイド・例文・解説。設定で「今日の学習」を一覧表示にもできます |
| 🎧 耳だけ復習 | 単語帳の「🎧 耳だけ」: 葡 → 考える間 → 和 → 葡 を読み上げ（向きと間は設定）。画面を見ずに聴けます（画面を消さない）。SRS には書かず、終わったら怪しかった語を選んで「1枚ずつで確認」で評価 |
| 🎯 クイズ | 5モード（葡→和 / 和→葡 / リスニング / **和→葡（入力）** / **書き取り（入力）**）・範囲（このデッキ / 学習済み / 今日の復習 / **苦手** / 一般語彙 / カポエイラ / 曲の単語）・5 / 10 / 20問。**1問ごとに SRS に反映**。入力式はアクセント違い・小さなつづり誤りを「惜しい」と判定し、ヒント（頭文字 → 伏せ字）・「正解にする」あり。解答カードで綴り・発音・例文を確認。最後に「間違えた問題をもう一度」（SRS には書かない）。デッキ画面から「このデッキでクイズ」 |
| 🔤 活用表 | 動詞のカードの裏面・単語帳に折りたたみで表示。現在・完了過去・不完了過去・未来 ＋ 現在分詞・過去分詞を4人称（eu / você・ele / nós / vocês・eles）で。タップで発音（自動生成の表） |
| 🔤 活用ドリル | 不規則動詞（活用表の55語）と、学習した規則動詞から出題。時制・人称を選んで活用形を入力。アクセント違いは「惜しい」、別の人称の形は不正解にしてどの形かを説明。最初に間違えた問題は最後にもう一度。成績（苦手な形）で出題を重み付け |
| 🔁 パターンプラクティス | 文型のスロットを語彙で入れ替え。**見て覚える**（文型の一覧。「カポエイラ：誘う」のようなカテゴリは「：」の前でまとめ、タップで開く）/ **発話ドリル**（全文型から混ぜて10問。和文を見て言う → 答えと音声 → 言えた・惜しい・言えなかった。言えなかった文は最後にもう一度）/ **オート**（和文 → 考える間 → 音声 を自動で繰り返す） |
| 📖 チャンクリーディング | 意味のカタマリ(/)で**1行ずつ改行した連結長文**を前から理解。全文再生は1文を1回の発話で読む（自然な抑揚）・文ごとの ▶・チャンク個別再生・訳の出し入れ(サイトトランスレーション)・**「ポルトガル語を隠す」で瞬間作文**（訳を見て言う → タップで答えと音声）。一覧は難易度（短文 / 中文 / 長文）と**話題**（食事・旅行・文化・カポエイラ など）で絞り込み、文の数と ❓設問の数を表示。設問のある読み物は本文の後に **❓ 内容チェック**（下） |

| 🧑‍🏫 AI先生（任意） | どの画面でも右下の 🧑‍🏫 からチャットで質問できる先生（Gemini 無料枠が既定・Claude も可。自分の API キー）。歌詞の行・歌詞の単語・文型・単語カード・クイズの答え・教材の文の「🧑‍🏫 先生に聞く」からは、いま見ている内容を付けて聞ける。例文は 🔊 と読み（カナ）付きのカードで出る。会話の履歴は端末だけ（下の「🤖 AI（任意）」。Gemini のキーの作り方もここ） |

**教材の数**（同梱。自作教材は別）: 読み物 24編（短文 8・中文 9・長文 7。話題つき・うち20編に内容チェック 60問）・シャドーイングのスクリプト 14本（会話 12・語り 2。短文 6・中文 5・長文 3）・ディクテーション 36問（短 / 中 / 長 各12）・パターンプラクティスの文型 30（入れ替える語 170）。カポエイラの語彙は増やしていません（カテゴリの整理だけ。下の「データの編集・追加」）。

- **間隔反復(SRS)**: SM-2簡易版で復習タイミングを自動最適化。ホームに「今日の復習」「新規語」「ストリーク」「習熟度」、単語と練習（🎵 音楽）の時間の目標を表示。
- **発音ガイド**: pt-BRの発音規則をルールベースでカタカナ/IPAに自動変換（全語対応）。
- **音声**: ブラウザ内蔵の音声合成(Web Speech API, pt-BR)。`src/services/audio.ts` を差し替えれば将来クラウドTTSや録音音源にも対応可能。
- **音声認識**（任意）: Web Speech API の SpeechRecognition（pt-BR）。`src/services/speechInput.ts` の `SpeechInputProvider` の後ろにあり、ほかの認識エンジンに差し替えられます。採点は `src/services/grade.ts` の `scoreSpeechWord` / `scoreSpeechSentence`。

### 新しい語の出る順番

今日の学習で導入する新しい語（1日の上限は設定。既定15語）は、次の順で選びます（`src/srs/queue.ts` の `orderNew`）。

1. クイズの「今日の学習に追加」で優先して出すようにした語
2. **コア語**（`data/core-order.json` の順）: 挨拶・代名詞・基本動詞・サバイバル表現・疑問詞・機能語・口語・数・時間・カポエイラ中核語を、区分ごとに少しずつ巡回する並び。初日から挨拶・動詞・機能語が混ざります。
3. コア語を使い切ったら、単語帳のカテゴリを巡回して選びます。

- **カポエイラ語の割合**（設定: 混ぜない / 4語に1語（既定）/ 3語に1語 / 2語に1語）で、カポエイラ語を一般語彙に混ぜます。
- 固有名詞・別名として登録した重複語（`data/word-aliases.json`）は出しません。同じ綴りの語は1日1語まで。
- 選んだ語は日ごとに並べ替え、同じカテゴリが続かないように散らします。今日の学習では復習4枚ごとに新しい語を1枚はさみます。

## 🤖 AI（任意）: 🧑‍🏫 AI先生・歌詞の AI 翻訳

設定に**自分の API キー**を入れたときだけ使える任意の機能です。**キーが無ければ AI のサービス（Google・Anthropic）とは一切通信しません**（ほかの機能はこれまでどおり動きます）。

- **🧑‍🏫 AI先生**: どの画面からでも開けるチャットの先生。歌詞の意味や文脈、文型の例文をもっと、こんな場面ではどう言う？などを聞けます（下の「🧑‍🏫 AI先生」）。
- **🤖 歌詞の AI 翻訳**: 曲全体の流れ・口語・比喩をくみ取った和訳（💡 補足つき。音楽タブの「🤖 AI翻訳」）。

### 使うサービス（設定の「🤖 AI」で選ぶ）

| | Gemini（Google AI Studio） | Claude（Anthropic） |
|------|------|------|
| 位置づけ | **既定・おすすめ** | 任意 |
| 料金 | **無料枠で 0円**。課金（請求先アカウント）を有効にしなければ請求されない（上限に達したら止まるだけ） | 有料（利用者の Anthropic アカウントに請求。歌詞の AI 翻訳は1曲あたり約2〜23円） |
| モデル | 3.8 Flash（賢さ優先・既定）/ 3.5 Flash-Lite（速さ・回数優先） | Haiku 4.5（既定）/ Sonnet 5 / Opus 5 |
| 送った内容 | 無料枠では Google の製品改善に使われ、人が読むこともある（下の ⚠） | Anthropic の規約に従う |

- 選んだ方にキーが無く、もう一方にあれば、キーがある方を使います（`src/services/ai/index.ts`）。AI先生と歌詞の AI 翻訳は、同じサービス・同じキーを使います。
- Gemini の 3.8 Flash が回数の上限（429）のときは、その回だけ 3.5 Flash-Lite で1回だけ頼み直し、答えたモデルを表示します。どちらも上限なら、選んだモデルの案内（「1分あたりの上限。約N秒待って」「今日の上限。明日また」など）を出します。どちらの SDK も自動の再試行はしません（無料枠の回数を黙って使わない・二重に請求しない）。
- サービス・モデルの選択（`aiProvider`・`geminiModel`・`aiTranslateModel`）は普通の設定としてバックアップに入ります（キーは入りません）。

### Gemini の準備（無料・数分）

1. [aistudio.google.com](https://aistudio.google.com) を開いて、Google アカウントでログインします（**18歳以上**が対象です）。
2. 「Get API key」でキーを作り、表示された `AIza` で始まるキーをコピーします。
3. アプリの 設定 →「🤖 AI（先生・歌詞のAI翻訳）」の Gemini の欄に貼り付けて「保存」し、「接続テスト」（選んだモデルに短いメッセージを1回送る。無料枠の回数を1回使う）で確かめます。
4. **課金（Billing・請求先アカウント）は設定しなくて大丈夫です**。設定しなければ無料枠のまま 0円で使え、上限に達したらその日（またはその1分）は止まるだけで、料金は発生しません。
5. 回数の上限（1分あたり・1日あたり）はプロジェクトごとに違い、**AI Studio で確認できます**。上限に達すると、先生・AI 翻訳が「無料枠の1分あたりの上限に達しました。約N秒待って…」「無料枠の今日の上限に達しました。明日また…」と案内します。

> ⚠ **無料枠（Unpaid Services）の注意**: 送った内容（質問・歌詞の行・学習のようす）と AI の返事は、Google の製品改善に使われ、人（レビュー担当者）が読むこともあります。**個人情報や秘密は書かないでください。** 設定の Gemini の欄、キーが無いときの先生のシート、先生の入力欄の下、AI 翻訳の確認にも同じ注意を出します。

### Claude の準備（任意・有料）

1. [console.anthropic.com](https://console.anthropic.com) でアカウントを作ってログインします。
2. Billing（支払い設定）でクレジットを購入します。**Limits で月の利用上限（spend limit）を低めに設定しておくことをおすすめします**（使いすぎ・キーの流出に備えて）。
3. 「API Keys」→「Create Key」でキーを作り、表示された `sk-ant-` で始まるキーをコピーします（作ったときに一度しか表示されません）。
4. アプリの設定 →「🤖 AI（先生・歌詞のAI翻訳）」の Claude の欄に貼り付けて「保存」し、「接続テスト」（選んだモデルに短いメッセージを1回送る。料金はごくわずか）で確かめます。Claude を使うには、同じ画面の上の「Gemini / Claude」の切り替えで Claude を選びます（Gemini のキーが無ければ、選ばなくても Claude を使います）。

### API キーの扱い（Gemini・Claude とも）

- **この端末にだけ**保存します（`bp-secrets-v1`・`src/store/useSecrets.ts`。**バックアップ・エクスポート・統合インポートには一切入りません**。ログにも URL にも出しません。Gemini のキーは SDK がヘッダー `x-goog-api-key` で送ります）。画面に出すのは末尾4文字だけです。
- 入力欄は（伏せ字を CSS で出せる Chrome などでは）パスワード欄にしていません（Chrome がキーを Google パスワード マネージャーに保存・同期しないように。伏せ字は「表示 / 隠す」で切り替え）。
- 設定の「削除」でいつでも消せます（削除・別のキーへの差し替えをすると、通信中の AI 翻訳・AI先生の返事も止めます）。インストールしたアプリとブラウザのタブのように**同じ端末でアプリを2つ開いていても**、片方で削除したキーをもう片方が書き戻すことはありません（別の窓の変更を読み直し、キーが変わったら通信も止める）。端末を人と共用するときは、使い終わったら削除してください。
- 実装: `src/services/ai/`（共通の呼び出し口 `types.ts`・`gemini.ts`（公式 SDK `@google/genai`）・`claude.ts`（公式 SDK `@anthropic-ai/sdk`）・選び方 `index.ts`。どちらの SDK も呼ぶときだけ読み込み（最初の画面のバンドルに入れない）、自動再試行はしない）。

### 🧑‍🏫 AI先生

歌詞のこの行はどういう文脈・どういう意味？、このパターンの例文をもっと欲しい、こんな場面ではどう言う？などを、いつでも聞けるチャットの先生です。キーが無いときは、シートに Gemini（無料枠）のキーの作り方と「⚙ 設定を開く」を出します。

- **開き方（入口）**:
  - **どの画面でも右下の 🧑‍🏫**（浮かぶボタン）。今の画面の名前を文脈にして開きます（開いていた会話があれば、その続き）。1枚ずつ学習・耳だけ復習の間と、文字を入力している間は隠します。曲の画面では「⤵ 現在行へ」の上。
  - **各画面の「🧑‍🏫 先生に聞く」**: いま見ている内容を文脈として付けて、新しい会話で開きます。
    - 🎵 歌詞の各行の 🧑‍🏫（時刻のチップの下）: その行・前後2行・今出している訳
    - 🔤 歌詞の単語シートの「🧑‍🏫 聞く」: 形・原形・意味・品詞・その行
    - 🧩 パターンプラクティスの文型のカードと発話ドリルの答え: 文型・和文の型・今の文・入れ替え語
    - 📖 1枚ずつ学習の裏面・単語帳の一覧（葡・和の両方が見えているとき）・クイズの答え: 単語・例文・間違えて選んだ語
    - 💬 シャドーイングの各文・ディクテーションの STEP 4・チャンクリーディングの各文（ポルトガル語を隠している間は出さない）
  - **開くだけで、自動では送りません**（すぐ聞ける質問のチップを押すか、入力して送る）。歌詞の「先生に聞く」から開くときは再生を止めます。浮かぶボタンから開いたときは再生を続けますが、シートを開いている間は歌詞の自動スクロールと、プレイリストの次の曲への画面の切り替えを休みます（戻る操作の履歴がずれないように）。
- **すぐ聞ける質問**（文脈の種類ごと）: 歌詞の行「この行の意味と文脈 / 比喩・言葉遊びは？ / 文法を分解して / 日常会話でも使う？」、単語「使い方と例文 / 似た語との違い / 覚え方のコツ」、文型「例文をもっと5つ / こんな場面ではどう言う？ / 丁寧・くだけた言い方」、文「この表現の使いどころ / 言い換えは？ / 文法を説明して」、画面「〜って何て言う？ / 発音のコツ / 今日の復習語で例文を」。「〜」のある質問は入力欄に入れて「〜」を選んだ状態にします（書き足して送る）。
- **先生の答え方**（システムプロンプト。`src/services/ai/teacherPrompt.ts`）: 日本語で簡潔に。ブラジルで実際に使う言い方（você・a gente）、【口語】【丁寧】【スラング】の印、地域差。文法はやさしく、例を添える。例文は「🇧🇷 ポルトガル語」の行と「🇯🇵 意味」の行の組で書かせ、画面では**例文カード**（🔊 読み上げ・カナ・意味）にします。歌詞は意味・ニュアンス・比喩・文化の背景（アフロ・ブラジル、カポエイラ、地方の言葉）を説明し、まるごと書き写さない。分からないことは分からないと言う。送る会話は最後の 20 発言まで。
- **画面**: 返事は少しずつ表示（入力中の点・「■ 停止」）。途中で止めた返事は「停止しました」の印を付けて残し（上限で 3.5 Flash-Lite が答えていたら、そのモデル名で）、1文字も届く前に止めたときは「返事が届く前に停止しました」と「再試行」を出します。失敗はその場に出して「再試行」（自動では送り直さない）。見出しの「🕘 履歴」で過去の会話を開く・消す、「＋ 新しい会話」、文脈のチップの × で文脈を外せます。キーボードが出ても最新の返事の最後が隠れないよう、一番下を見ていれば一番下へ送ります。Android の戻る操作でシートを閉じます（開くときに同じ URL の履歴を1つ積む。HashRouter の画面の履歴は変えない）。Gemini のときは入力欄の下に「無料枠の内容は Google の改善に使われます。個人情報は書かないでください」。返事はすべて React の文字として出し、HTML として差し込みません。
- **送るもの**: 質問を送ったときだけ、質問・会話の続き（最後の 20 発言）・文脈（歌詞の行なら前後2行と今の訳・曲名・アーティスト名）・**学習のようす**（学習した語の数と習得の数・最近つまずいた語（最大5語）と今日復習した語（最大8語）。意味つきで、歌から足した語は自分で付けた意味。興味＝カポエイラ）を、この端末から Google（Gemini）か Anthropic（Claude）に直接送ります（アプリにサーバーはありません）。学習のようすは、文脈のチップを外しても送ります。
- **会話の履歴**: **この端末にだけ**保存します（`bp-teacher-v1`・`src/store/useTeacher.ts`。新しい順に 30件 × 1つの会話に 100発言まで。文字数の合計にも上限）。**バックアップ・エクスポート・統合インポートには一切入らず、進捗のリセットでも消えません**（会話に歌詞の行や質問が入るため）。消すのは設定「🤖 AI」の「会話の履歴をすべて消す」か、先生のシートの履歴（1件ずつ・すべて）。同じ端末でアプリを2つ開いていても、片方で消した会話をもう片方が書き戻すことはありません（別の窓の変更を読み直す）。
- 実装: `src/services/ai/teacherContext.ts`（文脈を作る関数・シートの状態）・`teacherPrompt.ts`（プロンプト・学習者のようす・すぐ聞ける質問）・`format.ts`（返事を段落・箇条書き・太字・例文カードに分ける）・`teacherChat.ts`（送受信・停止・再試行）・`src/store/useTeacher.ts`（会話の履歴）・`src/components/teacher/`（シート・発言・浮かぶボタン・「先生に聞く」ボタン）。

### 配信（GitHub Pages）

1. `npm run check` を通して、変更を **コミット** します（未コミットの変更があると配信を止めます。どうしてもそのまま出すときは `npm run deploy -- --allow-dirty`）。
2. `npm run deploy` を実行します。型チェック → OneDrive の外の一時フォルダでビルド → 必要なファイルと noindex を確認 → 成果物だけの1コミットを `gh-pages` ブランチへ force push します（gh-pages は履歴を持ちません）。
3. 1〜2分で公開 URL に反映されます。Android ではアプリを開き直すと更新バナーが出ます。

初回の準備（リポジトリ作成・`gh auth setup-git`・Pages の有効化）は、origin が無いときに `npm run deploy` が手順を表示します。

> **OneDrive 上のビルドについて**: 本プロジェクトは OneDrive 同期フォルダ内にあり、同期がビルド出力(dist)のファイルをロックすると Vite がクラッシュすることがあります。これを避けるため `npm run build` は内部で **同期外の一時フォルダにビルドしてから dist/ へ複製** します(`scripts/build.mjs`)。`dist/` への複製に失敗した場合も成果物は一時フォルダに残り、メッセージに場所が表示されます。OneDrive を一時停止すれば確実に dist/ に出力できます。`npm run deploy` と `npm run preview:tmp` も一時フォルダでビルドします。なお `npm run dev` は影響を受けません。

※音楽タブはオンライン必須です。歌詞は再生時に [LRCLIB](https://lrclib.net) から端末で取得し、端末内にだけ保存します（**歌詞・和訳はアプリに同梱していません**）。`index.html` を `file://` で直接開くと YouTube 埋め込みが再生できないため、公開 URL か `npm run dev` / `npm run preview` などの http(s) で開いてください。音楽タブを離れる・画面をロックすると再生は止まります。

## 🎵 音楽タブ

- 再生リストは `data/music-playlists.json`（動画ID・曲名・アーティスト・長さ・LRCLIBの版IDのみ）。曲を追加したら `npm run music:pin` で歌詞の版を固定します。
- 再生リストは2つ: **ブラジル音楽**（21曲）と **ディズニー（ポルトガル語吹替）**（20曲）。一覧の上のタブで切り替えます。連続再生と ⏮ ⏭ は、その曲の再生リストの中だけで回ります（「‹ 一覧」で戻ると同じタブ）。
  - ディズニーはプリンセスの歌の**ブラジルポルトガル語吹替版**（シンデレラ・眠れる森の美女・リトル・マーメイド（実写・2023）・美女と野獣・アラジン（実写・2019）・ポカホンタス・ムーラン・プリンセスと魔法のキス・塔の上のラプンツェル・メリダとおそろしの森・アナと雪の女王 1/2・モアナと伝説の海 1/2・ウィッシュ）。動画は Disney の公式チャンネル（DisneyMusicBRVEVO・Disney Jr. Brasil）で、埋め込み再生できるものだけ。ポルトガル（欧州）版の吹替は入れていません。映画名は一覧と曲画面に小さく表示します（曲の `film`）。
  - リトル・マーメイドの「Parte Do Seu Mundo」とアラジンの2曲（「Um Mundo Ideal」「Ninguém Me Cala」）は**実写版**の吹替です（映画名に「実写」と表示）。アニメ版（1989・1992）のブラジル吹替は LRCLIB に同期歌詞が無いため、歌詞と一緒に学べる実写版にしています。アニメ版の公式動画（Disney Jr. Brasil の `shQSv9y8LwM`・`uXu-pB_OOV4`。後者は画面に歌詞が出る「com letra」）に替えるときは、その曲を `lrcMissing: true`・`lrclibId: null` にし、`film` と再生リストの `url` も直します（「Ninguém Me Cala」はアニメ版がありません）。
  - LRCLIB に動画と合う正しい歌詞が無い曲（別言語の歌詞しか無い・別の歌手の版しか無い）は `lrcMissing: true` にして歌詞を取りに行きません（誤った歌詞を出さないため。一覧に「歌詞なし」）。ディズニーでは5曲（シンデレラ・眠れる森の美女・ポカホンタス・ムーラン・モアナ2）。「com letra」の動画は画面に歌詞が出ます。
  - 映画の場面の短い版（メリダ「O Céu Eu Vou Tocar」・美女と野獣「Bela」＝動画は歌詞の版より約9秒短く、最後の行は動画の終わりより後）や前奏の長い MV（アナと雪の女王2）は、歌詞の時刻がずれることがあります。「同期 ±0.5s」「⏱合わせる」で合わせてください。
  - 再生リストの「YouTube ›」は `watch_videos?video_ids=…` の形（開くたびに YouTube が一時的な再生リストを作る）。
- **単語の意味はオフライン辞書**で表示します（単語の意味・原形推定に AI・LLM は使いません）: 単語帳（1,295語）＋一般辞書 `data/dict-words.json`。活用形・複数形・縮約（do = de+o）・口語（tô, pra, cê）から原形を推定します（`src/services/lemmatize.ts`、不規則動詞は `data/verb-irregular.json`、縮約/口語は `data/colloquial.json`）。
- 実行時に AI（Google Gemini / Anthropic Claude の API）を使うのは、下の **🤖 AI翻訳（歌詞の和訳・任意）** と 🧑‍🏫 AI先生だけです（準備は上の「🤖 AI（任意）」）。利用者が設定で自分の API キーを入れたときだけ動き、キーが無ければ Google（Gemini）とも Anthropic とも一切通信しません（これまでどおり無料の機械翻訳だけ）。
- 辞書に無い語は、シートで機械翻訳の候補を出し、意味を直して自分の単語として追加できます。
- 曲から追加した単語は「🎵 曲の単語」デッキに入り、今日の学習（1日の上限は設定で変更可・一般語彙の新規枠とは別）とクイズにも出ます。
- 歌詞のタイミングがずれる曲は「同期 ±0.5s」または「⏱合わせる」（歌われている行の時刻ボタンをタップ）で調整できます（曲ごとに保存）。
- 単語を調べてシートを閉じると、その行の頭から聴き直します（設定「調べた後は行の頭から再開」）。
- 「行の後の間」（オフ / 1x / 1.5x）を選ぶと、1行ずつ停止・行リピートのときに、聴いた行の長さに合わせて間を空けてから自動で再開します（その間に言い返す）。
- 行の ✍ で「自分で訳す」: 空欄に自分の訳を書いてから機械翻訳と並べて比べ、自分の訳を保存するか機械翻訳を採用します。訳した行の印は**行のハッシュだけ**を保存します（歌詞の本文は保存しません）。
- 行の 🧑‍🏫（時刻のチップの下）で、その行を AI先生に聞けます（上の「🤖 AI（任意）」の「🧑‍🏫 AI先生」）。

#### 歌詞の和訳（無料の機械翻訳）

- 「🌐 和訳を作成」で、端末から無料の機械翻訳（Google の gtx → だめなら MyMemory）に送って和訳を作ります（`src/services/translate.ts`。押したときだけ送る）。訳は行ごとに ✏️ で直せます。
- **和訳の単位「訳: 文ごと / 行ごと」**（既定は文ごと）: 歌詞は1つの文が2〜3行に分かれていることが多く、行ごとに訳すと文の途中で切れた意味の通らない訳になりがちです。**文ごと**は、つながった行をまとめて1回で訳し（`src/services/lyricSentences.ts`）、訳を文の最後の行の下に出して、訳の範囲に左の線を引きます。**行ごと**は従来どおり1行ずつ訳します。
  - まとめる目安: 行末が `. ! ? …` でなく、次のどれか … 行末が `, ; :`／行末の語が que / de / pra / com / quando / meu などの「つなぎの語」（冠詞・前置詞・接続詞・所有詞）／次の行が小文字で始まる。é / vou / sei / quero のような動詞は文の終わりにもよく来るので、それだけではつなげません（「Você sabe como é」と次の文を1つにしない）。
  - 空行（間奏）と 7 秒を超える間はまたがず、最大 3 行・24 語まで。括弧だけの行（合いの手）は前後とつなげません。
- **口語形の正規化**: 機械翻訳に送る前に、意味が1つに決まる口語の短縮形だけを標準形に直します（`src/services/mtNormalize.ts`）。例: tô → estou、tá → está、tava → estava、pra → para、pro → para o、cê → você、né → não é、cadê → onde está、bora → vamos、d'água → de água。tão（estão / とても）・num（em um / não）・té のように意味が決まらない形は直しません。直すのは送る文だけで、画面の歌詞・保存キーは変えません。
- 表示の優先順位（行ごと）: 自分で直した訳 ＞ AI の訳 ＞（文ごとのとき）文の訳 ＞ 行の機械翻訳。「機械翻訳で作り直す」は自分で直した訳・AI の訳を上書きしません。文の訳も**文の本文のハッシュ**をキーに保存し、バックアップに含まれます（各訳の任意項目 `source`・`note` も。形式は v3 のまま）。

#### 🤖 AI翻訳（Gemini＝無料枠・既定 / Claude＝任意・有料）

機械翻訳では意味が分かりにくいときのための任意の機能です。設定の「🤖 AI（先生・歌詞のAI翻訳）」に**自分の API キー**を保存したときだけ（キーの作り方・無料枠の注意は上の「🤖 AI（任意）」）、曲の画面に「🤖 AIで訳す（Gemini・無料）」または「（Claude・約N円）」が出ます。**キーが無ければ何も変わらず**、無料の機械翻訳だけを使います（Google・Anthropic とは通信しません）。

- **使うサービス**（設定で選ぶ。既定は Gemini）: 選んだ方にキーが無く、もう一方にあれば、キーがある方を使います（`src/services/ai/index.ts`）。
- **Gemini で訳す（既定・無料）**: 無料枠で 0円（課金＝請求先アカウントを有効にしなければ請求されません）。押すと無料枠の注意（送った歌詞の行と訳が Google の製品改善に使われ、人が読むこともある）を出して確認します。3.8 Flash が回数の上限（429）のときは、その回だけ 3.5 Flash-Lite で1回だけ頼み直し、どちらが訳したかを表示します。
- 以下の「訳し方・送るもの・保存するもの」はどちらのサービスでも同じです。「料金」は Claude のときだけです（Gemini は「無料枠」と出します）。

- **訳し方**: AI が**曲全体の流れ（誰が誰に何を言っているか・情景・気持ち）を踏まえて1行ずつ**訳します。口語・スラング・カポエイラやアフロ・ブラジルの言葉・比喩・言葉遊びをくみ取り、慣用句や文化の背景がある行にだけ 💡 の補足（80文字まで）を付けます。訳には「AI」の印が付きます。
- **送るもの**: 押すとモデルと料金の目安（Claude）・無料枠の注意（Gemini）を出して確認し、OK したときだけ、**歌詞の行**（同じ行は1回・空行は連の区切り。「(2x)」「---」のような訳すものが無い行は送らない）・曲名・アーティスト名を、この端末から Google（Gemini）か Anthropic（Claude）に直接送ります（アプリにサーバーはありません）。送ったデータの扱いは各社の規約に従います。
- **保存するもの**: 訳と補足を、行のハッシュをキーに `source: "ai"` で保存します（**歌詞の本文は保存しません**。補足に元の行がまるごと入っていたら「この行」に置き換えてから保存）。自分で直した訳は上書きせず、機械翻訳の訳は AI の訳に置き換えます。文のどの行にも AI の訳（か自分の訳）があれば、文ごとの機械翻訳は出しません。訳が返らなかった行だけは保存せず（今の訳のまま・画面に行数を出す）、行番号がずれた応答は何も保存しません。訳と補足はバックアップに入ります。
- **料金**: 利用者の Anthropic アカウントに請求されます（ドル建て）。1曲（40行）あたりの目安は **Haiku 4.5（既定・おすすめ）約2円 / Sonnet 5（より丁寧）約9円 / Opus 5（最高品質）約23円**（1ドル＝150円で計算）。Sonnet 5 / Opus 5 は考えながら訳す（effort は medium に抑えている）ため、その分も出力として課金されます（見積もりは多めに出します）。終わると「AI翻訳しました（今回 約N円）」と、応答のトークン数から計算した実際の額を出します。失敗しても自動では送り直しません（黙って二重に請求されないように。「再試行」で送り直す）。翻訳中は「中止」できますが、途中で止めても料金がかかる場合があります。オフラインでは押せません。
- **Claude の API キーの作り方・キーの扱い**（Gemini・Claude とも この端末だけ・バックアップに入らない）は、上の「🤖 AI（任意）」を見てください。サービス・モデルの選択は普通の設定としてバックアップに入ります（キーは入りません）。
- 実装: `src/services/ai/`（上の「🤖 AI（任意）」）・`src/services/aiTranslate.ts`（プロンプト・JSON スキーマで受け取った応答の検査・Claude の料金。Claude はモデルが構造化出力を受け付けなければ1回だけ JSON の本文で頼み直す）・`src/store/useSecrets.ts`（キー）・`src/store/aiRun.ts`（実行状態と中止）。

## データの編集・追加

学習データはすべて `data/` 配下のJSON（手編集しやすい形式）。

- `words.json` / `capoeira-words.json` … 単語（`カテゴリ/ポルトガル語/日本語/品詞`）。ID は並び順から作るため、並べ替え・削除はしないでください
- `examples.json` … 単語ごとの例文・コロケーション（キー=小文字のポルトガル語）
- `patterns.json` … パターン練習の文型（スロットの選択肢に `jaFull` があれば、その和文をそのまま表示）
- `passages.json` … チャンクリーディングのパッセージ（シャドーイングの読み物にもなります）。任意で `topic`（話題。日常 / 食事 / 旅行 / 文化 / カポエイラ / 仕事 / 健康 など）と `questions`（内容チェック: `[{ "q": "問い", "choices": ["3〜4個"], "answer": 0始まりの正解の番号, "explain": "解説（任意）" }]`）
- `scripts.json` … シャドーイングのスクリプト。任意で `level`（short / medium / long）と `kind`（`monologue` / `dialogue`）。`dialogue` は全行に `speaker`（話者の表示名）を書き、話者はちょうど2人（ロールプレイになる）
- `dictation.json` … ディクテーション項目（`level` は short / medium / long）
- 教材の数: `passages.json` 24編（全編に `topic`。20編に `questions` 計60問）・`scripts.json` 14本（全本に `level`。`dialogue` 12本）・`dictation.json` 36問・`patterns.json` 30文型。`npm run check:content` が形・ID の重複・話題や難易度の書き漏れ（一部にだけあると絞り込みで消える）を検査します
- `capoeira-category-map.json` … カポエイラ単語帳のカテゴリの付け替え（`{ "元のカテゴリ": "表示するカテゴリ" }`）。細かく分かれすぎたカテゴリ（「状態・方向」と「状態・評価」など）を読み込み時にまとめます。単語データと ID は変えません（デッキ・新しい語のカテゴリの巡回・クイズの誤答の「同じカテゴリ」に使う）。デッキの番号（`/flashcards/番号`）はずれますが、保存していないので進捗には影響しません。今回は付け替えだけで、カポエイラの語彙（`capoeira-words.json`）は追加・変更していません（15カテゴリ → 11カテゴリ）
- `pronunciation-overrides.json` … 自動生成が不自然な語のカナ/IPA上書き辞書
- `music-playlists.json` … 音楽タブの再生リスト（ブラジル音楽・ディズニー（ポルトガル語吹替）。メタデータのみ。歌詞は含まない）
- `dict-words.json` … 歌詞引き用の一般辞書（**追記専用**: ID が `dict:インデックス` のため並べ替え・削除禁止。誤りは日本語の修正か品詞 `_deleted` で対応。`dict-words.lock.json` で機械的に検査）
- `verb-irregular.json` … 不規則動詞の活用表（省略した時制は規則形・完了過去3複から自動派生）。活用表・活用ドリルもこれを使います
- `colloquial.json` … 縮約形・口語形・間投詞の分解表
- `core-order.json` … 新しい語を導入する順番の核（ID の配列。約150語）。手で編集せず、`scripts/build-core-order.ts` の SEED を直して `npm run core-order` で作り直します（未解決・曖昧・重複・別名の ID があれば書かずに止まります）
- `word-aliases.json` … 同じ意味の重複見出しの登録（`[{ "keep": "words:0294", "alias": ["capoeira:0049"], "pt": "メモ" }]`。keep は一般語彙側）。alias 側は新しい語として出さず、keep と同じ語として扱います。`npm run aliases` の候補を人が確認して、本当に同じ語だけを手で登録します

> **オーナーの確認待ち（word-aliases.json）**: 登録済みの別名（85件・87 ID）は候補から機械的に選んだものを含みます。特に banguela（capoeira:0235 ← 0270）・peixe（0241 ← 0366）・natureza（0350 ← 0855, 0995）を確認してください。chave・mercado・mesmo・frente・tocar は未登録（別語か重複かの判断待ち）です。登録を変えたら `npm run check` を通し、core-order が「複数ヒット」になったら SEED に ID を明記して `npm run core-order` を実行します。

例文のカナは自動生成されるため、`examples.json` には `pt` と `ja` だけ書けばOKです。

## 学習進捗のバックアップ

進捗はブラウザの localStorage に保存されます。設定画面の **バックアップを保存 / インポート** で、別端末への移行やバックアップができます（手順は上の「公開 URL と Android でのインストール」）。
含まれるもの: 単語の進捗・学習ログ・自作教材・活用ドリルの成績・設定（音声の選択は端末ごと）・音楽タブの和訳（自分で編集した訳・AI の訳と補足を含む）・同期調整・曲から追加した単語・✍ 自分で訳した行の印（行のハッシュのみ）。**歌詞そのもの、AI の API キー（Gemini・Anthropic）、AI先生との会話は含みません。**
形式は v3 で、古いアプリで作ったファイル（v1・v2）も読み込めます。

「進捗をリセット」は、単語の進捗・学習ログ・曲から追加した単語・✍ の印・活用ドリルの成績を消します（和訳・同期設定は教材なので残します。AI先生の会話の履歴も消しません）。

## 技術構成

Vite + React 18 + TypeScript + Tailwind CSS + Zustand（永続化）+ vite-plugin-pwa。HashRouter・バックエンド不要。
