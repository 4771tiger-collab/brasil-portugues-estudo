# ブラジルポルトガル語 学習帳 🇧🇷

日本語話者のためのブラジルポルトガル語 学習アプリ。一般語彙 **1,002語** ＋ カポエイラ専門 **293語**（＋歌詞引き用の一般辞書 3,784語）を、
言語習得で効果が高いとされる **間隔反復(SRS)・能動的想起・文脈学習・発音支援・発話練習** で学べます。
Android の Chrome で使う PWA です（バックエンド無し。学習データは端末の中だけに保存）。

## 公開 URL と Android でのインストール

**https://4771tiger-collab.github.io/brasil-portugues-estudo/**

1. Android の **Chrome** で上の URL を開きます。
2. ホームの「アプリとしてインストール」の **インストール** ボタン、または Chrome のメニュー **⋮ →「アプリをインストール」**（機種によっては「ホーム画面に追加」）でインストールします。インストールすると、ブラウザが学習データを消しにくくなります（設定の「データ保護」で状態を確認できます）。
3. 音声は端末の読み上げ（Google 音声サービス）を使います。pt-BR の音声が無いときは、設定の「Android で pt-BR の音声を入れるには」の手順で音声データを入れてください。
4. **更新**: 新しい版を配信すると、アプリを開き直したときにホームと設定に「新しいバージョンがあります」のバナーが出ます。「更新」を押すと画面を読み直します（学習の記録は消えません。学習の途中の画面ではバナーを出しません）。
5. **バックアップ**: 設定 →「⬇ バックアップを保存」で、Android では共有シートが開きます（Google ドライブ・メールなどへ）。ファイルは **.txt**（中身は JSON）ですが、そのままインポートできます（Chrome の共有は .json を送れないため）。PC では .json をダウンロードします。ホームには、前回から7日以上たつか 200 回以上評価すると保存の案内が出ます。
6. **インポート**: ファイルを選ぶか、テキストを貼り付けます。既定の **統合（推奨）** は、この端末の記録とバックアップの記録を合わせます（同じ語は新しく学習した方を残し、設定はこの端末のまま）。PC とスマホの記録をまとめるのにも使えます。**置き換え** は、この端末の進捗・曲のデータ・設定をバックアップの内容にします。

音楽タブ以外はオフラインでも動きます。シャドーイングのマイク録音は HTTPS（公開 URL）か `localhost` で動作します。音声認識の「🎤 言ってみる」（任意。既定はオフ）はオンラインのときだけ使えます。

## 学習機能

| 機能 | 内容 |
|------|------|
| 📇 今日の学習（1枚ずつ） | 表を見て思い出す → 答えを見る → 4段階で評価（もう一度 / 難しい / 正解 / 簡単）。**「もう一度」は同じ回の最後にもう一度出す（再学習）**・評価の直後に **取り消す**（1段。U / Ctrl+Z）・**期限前のカードは「もう一度」以外は据え置き**（間隔を変えない）。新しい語は紹介カード → 数枚後に確認。出題の向き（葡→和 / 和→葡 / ミックス）・答えを見たら自動で発音・キー操作（Space / 1〜4 / U / R）。完了画面に「もう一度」だった語。1日の復習の上限を超える日は、延滞の大きい語から出して新しい語はお休み |
| ✍ 産出カード（和→葡） | 理解カードの復習間隔が7日以上になった語から、**日本語を見てポルトガル語を言う**カードを理解カードとは別の SRS（カードのキーは `語のID@p`）で追加（1日の新規は設定で 0 / 3 / 5（既定）/ 10 語）。言ってから「答えを見る」で自己評価するか、**「✍ 入力して答える」**で採点（アクセント違い・小さなつづり誤りは「惜しい」、同じ意味の別見出しも正解）し、おすすめの評価を強調（選ぶのは自分）。今日の学習の1枚ずつでだけ出し、理解カードの間に散らす（今日の学習を一覧表示にしていても、産出カードだけの日は1枚ずつで開く）。**答えを見た直後に言わせない**: 同じ語（と同じ綴りの語）の理解カードを今日出す・今日評価した日は、産出カードを翌日に回す（一覧表示・🎧 耳だけ・「もう1周」でも、先にポルトガル語を見せてから同じ語を問うことはない。期限の数にも数えない）。1日の復習の上限は理解カードと合わせて数える。ホームに「ポルトガル語で言える語」。設定でオフにすると一時停止（記録は残る）。固有名詞・別名の語と、和訳に答えのポルトガル語が書かれている語（「お願いします（Por favor）」の favor など）は対象外 |
| 🎤 言ってみる（音声認識・任意） | 設定の「🎤 音声認識（言ってみる）」で説明を読んでオンにしたときだけ使えます（**既定はオフ**。オフのときはボタンも出ません）。話した音声は **Chrome が Google の音声認識サービスに送って文字にします**。アプリは音声も認識結果も保存しません（バックアップにも入れず、オン／オフも端末ごと）。オンライン時のみ。**✍ 産出カード**の表で 🎤 を押して言うと採点して裏返し、おすすめの評価を強調（入力と同じ正解の集合）。**シャドーイング**の1文ずつと**パターンプラクティス**の発話ドリル（答えの前に言って点数 → 答え）では、文の点数と語ごとの色分け。アクセント記号の違いは数えず、認識エンジンが数字・記号で書いた読み方も語に直して比べる（2 → dois / duas、504 → quinhentos e quatro（999,999 まで）、10% → dez por cento、R$ 60 → sessenta reais、5º → quinto、38° → trinta e oito graus）。文を言うときの聞き取りの上限は文の長さに合わせて延ばす（既定8秒、20語の文なら17秒）。設定の「テスト」で聞き取った文字を確かめられます |
| 📇 単語帳（一覧） | デッキ別に50語ずつ・目隠し(一括/個別タップ)・音声個別/連続再生(0.8/1.0/1.2x)・SRS評価・カナ/IPA発音ガイド・例文・解説。設定で「今日の学習」を一覧表示にもできます |
| 🎧 耳だけ復習 | 単語帳の「🎧 耳だけ」: 葡 → 考える間 → 和 → 葡 を読み上げ（向きと間は設定）。画面を見ずに聴けます（画面を消さない）。SRS には書かず、終わったら怪しかった語を選んで「1枚ずつで確認」で評価 |
| 🎯 クイズ | 5モード（葡→和 / 和→葡 / リスニング / **和→葡（入力）** / **書き取り（入力）**）・範囲（このデッキ / 学習済み / 今日の復習 / **苦手** / 一般語彙 / カポエイラ / 曲の単語）・5 / 10 / 20問。**1問ごとに SRS に反映**。入力式はアクセント違い・小さなつづり誤りを「惜しい」と判定し、ヒント（頭文字 → 伏せ字）・「正解にする」あり。解答カードで綴り・発音・例文を確認。最後に「間違えた問題をもう一度」（SRS には書かない）。デッキ画面から「このデッキでクイズ」 |
| 🔤 活用表 | 動詞のカードの裏面・単語帳に折りたたみで表示。現在・完了過去・不完了過去・未来 ＋ 現在分詞・過去分詞を4人称（eu / você・ele / nós / vocês・eles）で。タップで発音（自動生成の表） |
| 🔤 活用ドリル | 不規則動詞（活用表の55語）と、学習した規則動詞から出題。時制・人称を選んで活用形を入力。アクセント違いは「惜しい」、別の人称の形は不正解にしてどの形かを説明。最初に間違えた問題は最後にもう一度。成績（苦手な形）で出題を重み付け |
| 🔁 パターンプラクティス | 文型のスロットを語彙で入れ替え。**見て覚える**（文型の一覧。「カポエイラ：誘う」のようなカテゴリは「：」の前でまとめ、タップで開く）/ **発話ドリル**（全文型から混ぜて10問。和文を見て言う → 答えと音声 → 言えた・惜しい・言えなかった。言えなかった文は最後にもう一度）/ **オート**（和文 → 考える間 → 音声 を自動で繰り返す） |
| 📖 チャンクリーディング | 意味のカタマリ(/)で**1行ずつ改行した連結長文**を前から理解。全文再生は1文を1回の発話で読む（自然な抑揚）・文ごとの ▶・チャンク個別再生・訳の出し入れ(サイトトランスレーション)・**「ポルトガル語を隠す」で瞬間作文**（訳を見て言う → タップで答えと音声）。一覧は難易度（短文 / 中文 / 長文）と**話題**（食事・旅行・文化・カポエイラ など）で絞り込み、文の数と ❓設問の数を表示。設問のある読み物は本文の後に **❓ 内容チェック**（下） |
| 🗣️ シャドーイング | **1文シャドーイング**: 行ごとに ▶お手本 / ●録音 / ▶自分 / ⇄聞き比べ。慣れたら全文で通す（お手本の全文再生・スクリプト非表示）。速さは設定の速さから。一覧は **会話** / スクリプト / 読み物（チャンクリーディングの教材。自作を含む）に分け、難易度で絞り込み。会話は行ごとに話者のチップ（2色）と 🎭 ロールプレイ（下） |
| 🎭 会話スクリプトとロールプレイ | 2人の会話スクリプト12本（パン屋・青空市場・道を尋ねる・配車アプリ・レストラン・ホテルのチェックイン・電話で予約・週末のお誘い・服を買う・診察・カポエイラ教室の初日・ホーダのあとで）。シャドーイングの「会話」から開く。**ロールプレイ**: 自分の役を選ぶと相手のセリフだけを読み上げ、自分の番は「🗣 あなたの番」を出して考える間（max(1.5秒, 文字数×90ms÷速さ)）待つ。🎤 言ってみる がオンなら、その行を言って採点し「次へ」を押すまで待つ。止めた行から再開でき、画面を離れる・隠すと止まる（動いている間は画面を消さない）。最後まで通したら学習ログに1回 |
| ❓ 内容チェック問題 | 読み物20編に3問ずつ（計60問・3〜4択・解説つき）。チャンクリーディングの本文の後に出す。選択肢は読み物ごと・「もう一度」ごとに並べ替えて出す（正解の位置で当てられない）。答えは1回目で決まり、全問に答えたら学習ログに1回 |
| ✍️ ディクテーション | 4ステップ(聴取→語彙予習→ヒント入力→訳＋**オーバーラッピング**)・3レベル(短/中/長)・語ごとの色分け採点（正解の全文は最後まで出さない）・文ごとの ▶ と 0.6x・一覧は難易度ごとにまとめ（件数つきの絞り込み）、答えを伏せる |
| ➕ 教材を追加 | ポルトガル語テキストを貼り付け→自動チャンク分割→自分の教材に |
| 🎵 音楽 | YouTube再生リストを再生・**同期歌詞**(現在行ハイライト/自動スクロール/行リピート/1行ずつ停止/0.75x)・**和訳**(端末から無料機械翻訳→行ごとに編集)・**歌詞の単語をタップ→原形・活用・意味・発音→SRSに追加**・曲ごとの単語一覧。**改善**: 単語を調べた後は行の頭から聴き直す・**行の後の間**（1x / 1.5x）で言い返してから自動で再開・**✍ 自分で訳してから機械翻訳と比べる**（「自分で訳した行 N/M」） |

**教材の数**（同梱。自作教材は別）: 読み物 24編（短文 8・中文 9・長文 7。話題つき・うち20編に内容チェック 60問）・シャドーイングのスクリプト 14本（会話 12・語り 2。短文 6・中文 5・長文 3）・ディクテーション 36問（短 / 中 / 長 各12）・パターンプラクティスの文型 30（入れ替える語 170）。カポエイラの語彙は増やしていません（カテゴリの整理だけ。下の「データの編集・追加」）。

- **間隔反復(SRS)**: SM-2簡易版で復習タイミングを自動最適化。ホームに「今日の復習」「新規語」「ストリーク」「習熟度」、単語と練習（🎵 音楽）の時間の目標を表示。
- **発音ガイド**: pt-BRの発音規則をルールベースでカタカナ/IPAに自動変換（全語対応）。
- **音声**: ブラウザ内蔵の音声合成(Web Speech API, pt-BR)。`src/services/audio.ts` を差し替えれば将来クラウドTTSや録音音源にも対応可能。
- **音声認識**（任意）: Web Speech API の SpeechRecognition（pt-BR）。`src/services/speechInput.ts` の `SpeechInputProvider` の後ろにあり、ほかの認識エンジンに差し替えられます。採点は `src/services/grade.ts` の `scoreSpeechWord` / `scoreSpeechSentence`。

### 新しい語の出る順番

今日の学習で導入する新しい語（1日の上限は設定。既定15語）は、次の順で選びます（`src/srs/queue.ts` の `orderNew`）。

1. クイズの「今日の学習に追加」で優先して出すようにした語
2. **コア語**（`data/core-order.json` の順）: 挨拶・代名詞・基本動詞・サバイバル表現・疑問詞・機能語・口語・数・時間・カポエイラ中核語を、区分ごとに少しずつ巡回する並び。初日から挨拶・動詞・機能語が混ざります。
3. コア語を使い切ったら、単語帳のカテゴリを巡回して選びます。

- **カポエイラ語の割合**（設定: 混ぜない / 4語に1語（既定）/ 3語に1語 / 2語に1語）で、カポエイラ語を一般語彙に混ぜます。
- 固有名詞・別名として登録した重複語（`data/word-aliases.json`）は出しません。同じ綴りの語は1日1語まで。
- 選んだ語は日ごとに並べ替え、同じカテゴリが続かないように散らします。今日の学習では復習4枚ごとに新しい語を1枚はさみます。

## 開発

```bash
npm install             # 初回のみ
npm run dev             # 開発サーバー (http://localhost:5173)
npm run typecheck       # 型チェック（src と scripts の2つの tsconfig）
npm run check           # 型チェック＋下の check:* をすべて実行（コミット前に通す）
npm run build           # 本番ビルド（OneDrive の外でビルドして dist/ へ複製）
npm run preview         # dist/ をプレビュー
npm run preview:tmp     # 本番ビルドを一時フォルダに作って http://localhost:4173/ で確認（SW・manifest・更新バナー。--no-build で前回のビルドを配信）
npm run deploy          # GitHub Pages へ配信（下記）
```

### 配信（GitHub Pages）

1. `npm run check` を通して、変更を **コミット** します（未コミットの変更があると配信を止めます。どうしてもそのまま出すときは `npm run deploy -- --allow-dirty`）。
2. `npm run deploy` を実行します。型チェック → OneDrive の外の一時フォルダでビルド → 必要なファイルと noindex を確認 → 成果物だけの1コミットを `gh-pages` ブランチへ force push します（gh-pages は履歴を持ちません）。
3. 1〜2分で公開 URL に反映されます。Android ではアプリを開き直すと更新バナーが出ます。

初回の準備（リポジトリ作成・`gh auth setup-git`・Pages の有効化）は、origin が無いときに `npm run deploy` が手順を表示します。

> **OneDrive 上のビルドについて**: 本プロジェクトは OneDrive 同期フォルダ内にあり、同期がビルド出力(dist)のファイルをロックすると Vite がクラッシュすることがあります。これを避けるため `npm run build` は内部で **同期外の一時フォルダにビルドしてから dist/ へ複製** します(`scripts/build.mjs`)。`dist/` への複製に失敗した場合も成果物は一時フォルダに残り、メッセージに場所が表示されます。OneDrive を一時停止すれば確実に dist/ に出力できます。`npm run deploy` と `npm run preview:tmp` も一時フォルダでビルドします。なお `npm run dev` は影響を受けません。

※音楽タブはオンライン必須です。歌詞は再生時に [LRCLIB](https://lrclib.net) から端末で取得し、端末内にだけ保存します（**歌詞・和訳はアプリに同梱していません**）。`index.html` を `file://` で直接開くと YouTube 埋め込みが再生できないため、公開 URL か `npm run dev` / `npm run preview` などの http(s) で開いてください。音楽タブを離れる・画面をロックすると再生は止まります。

## 🎵 音楽タブ

- 再生リストは `data/music-playlists.json`（動画ID・曲名・アーティスト・長さ・LRCLIBの版IDのみ）。曲を追加したら `npm run music:pin` で歌詞の版を固定します。
- **単語の意味はオフライン辞書**で表示します: 単語帳（1,295語）＋一般辞書 `data/dict-words.json`。活用形・複数形・縮約（do = de+o）・口語（tô, pra, cê）から原形を推定します（`src/services/lemmatize.ts`、不規則動詞は `data/verb-irregular.json`、縮約/口語は `data/colloquial.json`）。
- 辞書に無い語は、シートで機械翻訳の候補を出し、意味を直して自分の単語として追加できます。
- 曲から追加した単語は「🎵 曲の単語」デッキに入り、今日の学習（1日の上限は設定で変更可・一般語彙の新規枠とは別）とクイズにも出ます。
- 歌詞のタイミングがずれる曲は「同期 ±0.5s」または「⏱合わせる」（歌われている行の時刻ボタンをタップ）で調整できます（曲ごとに保存）。
- 単語を調べてシートを閉じると、その行の頭から聴き直します（設定「調べた後は行の頭から再開」）。
- 「行の後の間」（オフ / 1x / 1.5x）を選ぶと、1行ずつ停止・行リピートのときに、聴いた行の長さに合わせて間を空けてから自動で再開します（その間に言い返す）。
- 行の ✍ で「自分で訳す」: 空欄に自分の訳を書いてから機械翻訳と並べて比べ、自分の訳を保存するか機械翻訳を採用します。訳した行の印は**行のハッシュだけ**を保存します（歌詞の本文は保存しません）。

## データの編集・追加

学習データはすべて `data/` 配下のJSON（手編集しやすい形式）。

- `words.json` / `capoeira-words.json` … 単語（`カテゴリ/ポルトガル語/日本語/品詞`）。ID は並び順から作るため、並べ替え・削除はしないでください
- `examples.json` … 単語ごとの例文・コロケーション（キー=小文字のポルトガル語）
- `patterns.json` … パターン練習の文型（スロットの選択肢に `jaFull` があれば、その和文をそのまま表示）
- `passages.json` … チャンクリーディングのパッセージ（シャドーイングの読み物にもなります）。任意で `topic`（話題。日常 / 食事 / 旅行 / 文化 / カポエイラ / 仕事 / 健康 など）と `questions`（内容チェック: `[{ "q": "問い", "choices": ["3〜4個"], "answer": 0始まりの正解の番号, "explain": "解説（任意）" }]`）
- `scripts.json` … シャドーイングのスクリプト。任意で `level`（short / medium / long）と `kind`（`monologue` / `dialogue`）。`dialogue` は全行に `speaker`（話者の表示名）を書き、話者はちょうど2人（ロールプレイになる）
- `dictation.json` … ディクテーション項目（`level` は short / medium / long）
- 教材の数: `passages.json` 24編（全編に `topic`。20編に `questions` 計60問）・`scripts.json` 14本（全本に `level`。`dialogue` 12本）・`dictation.json` 36問・`patterns.json` 30文型。`npm run check:content` が形・ID の重複・話題や難易度の書き漏れ（一部にだけあると絞り込みで消える）を検査します
- `capoeira-category-map.json` … カポエイラ単語帳のカテゴリの付け替え（`{ "元のカテゴリ": "表示するカテゴリ" }`）。細かく分かれすぎたカテゴリ（「状態・方向」と「状態・評価」など）を読み込み時にまとめます。単語データと ID は変えません（デッキ・新しい語のカテゴリの巡回・クイズの誤答の「同じカテゴリ」に使う）。デッキの番号（`/flashcards/番号`）はずれますが、保存していないので進捗には影響しません。今回は付け替えだけで、カポエイラの語彙（`capoeira-words.json`）は追加・変更していません（15カテゴリ → 11カテゴリ）
- `pronunciation-overrides.json` … 自動生成が不自然な語のカナ/IPA上書き辞書
- `music-playlists.json` … 音楽タブの再生リスト（メタデータのみ。歌詞は含まない）
- `dict-words.json` … 歌詞引き用の一般辞書（**追記専用**: ID が `dict:インデックス` のため並べ替え・削除禁止。誤りは日本語の修正か品詞 `_deleted` で対応。`dict-words.lock.json` で機械的に検査）
- `verb-irregular.json` … 不規則動詞の活用表（省略した時制は規則形・完了過去3複から自動派生）。活用表・活用ドリルもこれを使います
- `colloquial.json` … 縮約形・口語形・間投詞の分解表
- `core-order.json` … 新しい語を導入する順番の核（ID の配列。約150語）。手で編集せず、`scripts/build-core-order.ts` の SEED を直して `npm run core-order` で作り直します（未解決・曖昧・重複・別名の ID があれば書かずに止まります）
- `word-aliases.json` … 同じ意味の重複見出しの登録（`[{ "keep": "words:0294", "alias": ["capoeira:0049"], "pt": "メモ" }]`。keep は一般語彙側）。alias 側は新しい語として出さず、keep と同じ語として扱います。`npm run aliases` の候補を人が確認して、本当に同じ語だけを手で登録します

> **オーナーの確認待ち（word-aliases.json）**: 登録済みの別名（85件・87 ID）は候補から機械的に選んだものを含みます。特に banguela（capoeira:0235 ← 0270）・peixe（0241 ← 0366）・natureza（0350 ← 0855, 0995）を確認してください。chave・mercado・mesmo・frente・tocar は未登録（別語か重複かの判断待ち）です。登録を変えたら `npm run check` を通し、core-order が「複数ヒット」になったら SEED に ID を明記して `npm run core-order` を実行します。

例文のカナは自動生成されるため、`examples.json` には `pt` と `ja` だけ書けばOKです。

## 学習進捗のバックアップ

進捗はブラウザの localStorage に保存されます。設定画面の **バックアップを保存 / インポート** で、別端末への移行やバックアップができます（手順は上の「公開 URL と Android でのインストール」）。
含まれるもの: 単語の進捗・学習ログ・自作教材・活用ドリルの成績・設定（音声の選択は端末ごと）・音楽タブの和訳（自分で編集した訳を含む）・同期調整・曲から追加した単語・✍ 自分で訳した行の印（行のハッシュのみ）。**歌詞そのものは含みません。**
形式は v3 で、古いアプリで作ったファイル（v1・v2）も読み込めます。

「進捗をリセット」は、単語の進捗・学習ログ・曲から追加した単語・✍ の印・活用ドリルの成績を消します（和訳・同期設定は教材なので残します）。
